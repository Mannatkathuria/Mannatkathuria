### 🧮 Algorithm Analyzer

A project direction focused on making algorithms less of a black box.

Think:

```text

  ↓
Algorithm
  ↓
Execution
  ├── Time
  ├── Memory
  ├── Operations
  └── Visualization
  ↓
ANALYSIS
```

Because knowing *what* an algorithm does is one thing.

Knowing **why it behaves that way** is another.
